# 快捷键
1. `Ctrl+G` 等快捷键中的字母表示按键名称，除非明确列出，否则不需要按住 `Shift`。阅读模式的导航按键区分大小写。
2. 在 macOS 下，`Ctrl` 通常对应 `Command`，但 Vi 模式及下文特别注明的阅读快捷键除外。下文的标准文本选择快捷键采用 Windows/Linux 的按键名称；macOS 使用其系统文本导航快捷键。
3. 按键序列 `Ctrl+G, I` 表示先同时按下 `Ctrl` 和 `G`，释放，然后按下并释放 `I`。
4. 以下列出的是**常用默认快捷键**。查看或修改可配置的快捷键，请打开**设置 → Edit JSON**，编辑 `vnotex.json`：通用快捷键位于 `core.shortcuts`，编辑器操作位于 `editor.core.shortcuts`。保存并重启 VNote 后使用修改后的快捷键。内置的阅读导航和文本输入按键并非全部列在该文件中。
5. **设置 → 通用 → 允许 Ctrl+Alt 快捷键**默认开启。关闭后，包含 `Ctrl+Alt` 的已配置快捷键（包括全局热键）将在重启后禁用，以避免与某些键盘布局的 AltGr 冲突；这不会删除已配置的快捷键。

## 通用
- `F11`  
切换主窗口全屏。
- `F10`  
切换主窗口置顶。
- `Ctrl+G, E`  
切换是否扩展内容区。
- `Ctrl+Alt+P`  
打开设置。
- `Ctrl+Alt+N`  
在当前文件夹下新建笔记。
- `Ctrl+Alt+S`  
在当前文件夹下新建文件夹。
- `Ctrl+Alt+Q`  
启动快速笔记捕获（全局热键）。
- `Ctrl+Alt+U`  
显示主窗口（全局热键）。
- `Ctrl+Alt+I`  
打开第一个快速访问项目。
- `Ctrl+G, G`  
打开统一入口。
- `Ctrl+G, T`  
打开导出。
- `Ctrl+Shift+T`  
重新打开上一个关闭的文件。
- `Ctrl+G, X`  
隐藏当前获得焦点的停靠面板；否则关闭当前标签页。
- `Ctrl+G, D`  
在导航面板中定位当前笔记。
- `Ctrl+J`/`Ctrl+K`  
在支持 Vi 风格导航的部件中向下或向上移动。这些部件导航键在 macOS 下使用键盘上的 **Control** 键，与下文 VSCode 编辑器的按键绑定不同。

全局热键需要 VNote 正在运行，并且操作系统允许注册这些热键。
搜索面板没有默认的激活快捷键。可以从侧边栏打开，或在 `vnotex.json` 中配置 `core.shortcuts.SearchDock`。

### 面板和焦点
- `Ctrl+G, A`  
激活笔记本面板。
- `Ctrl+G, U`  
激活大纲面板。
- `Ctrl+G, S`  
激活片段面板。
- `Ctrl+G, C`  
激活位置列表面板。
- `Ctrl+G, Y`  
将焦点移到当前笔记的内容区。

### 标签页和分栏
使用作用于分栏的快捷键时，请先将焦点放在笔记或其标签页区域中。

- `Ctrl+G, 1` 到 `Ctrl+G, 9`  
激活当前分栏中对应的标签页。
- `Ctrl+G, 0`  
切换到当前分栏中上一个激活的标签页。
- `Ctrl+G, N`/`Ctrl+G, P`  
激活下一个或上一个标签页。
- `Ctrl+G, \`  
在右侧新建分栏。
- `Ctrl+G, -`  
在下方新建分栏。
- `Ctrl+G, Shift+\`  
最大化当前分栏。
- `Ctrl+G, =`  
均匀分布各个分栏。
- `Ctrl+G, R`  
移除当前分栏及其工作区。
- `Ctrl+G, H`/`Ctrl+G, J`/`Ctrl+G, K`/`Ctrl+G, L`  
将焦点移到左方、下方、上方或右方的分栏。
- `Ctrl+G, Shift+H`/`Ctrl+G, Shift+J`/`Ctrl+G, Shift+K`/`Ctrl+G, Shift+L`  
将当前标签页移到左方、下方、上方或右方的分栏。
- `Ctrl+G, Shift+D`  
将当前标签页分离为独立窗口。

## 笔记视图
以下命令作用于当前视图，不限于 VSCode 输入模式；是否可用取决于当前文档类型。

- `Ctrl+F`  
打开当前笔记的查找和替换（PDF 仅支持查找，不支持替换）。
- `F3`/`Shift+F3`  
使用上次的搜索条件查找下一个或上一个匹配项。
- `Ctrl+G, Space`  
清除 Markdown 和文本笔记中的搜索高亮，也适用于 Markdown 阅读模式。
- `Ctrl+G, O`  
在 Markdown 或 PDF 中打开工具栏的大纲弹出窗口，与大纲面板快捷键 `Ctrl+G, U` 不同。
- `Ctrl+=`/`Ctrl+-`  
放大或缩小。
- `Ctrl+0`  
重置缩放。
- `F9`  
切换 Markdown、文本或 PDF 的演示模式。Markdown 会切换到阅读模式并显示幻灯片。
- `Escape`  
退出演示模式；如果打开了弹出窗口，则先关闭弹出窗口。

## 文本编辑器
保存和缩放是编辑器的通用命令。下列文本输入按键适用于默认的 **VSCode** 输入模式。可在**设置 → 文本编辑器 → 输入模式**中选择输入模式；普通和 Vi 模式使用不同的按键绑定。

- `Ctrl+S`  
保存当前更改。
- `Ctrl+Wheel`  
使用鼠标滚轮放大或缩小。
- `Ctrl+J`/`Ctrl+K`  
向下或向上滚动，不移动光标。
- `Ctrl+Space` 或 `Ctrl+N`/`Ctrl+P`  
激活单词补全。
    - `Ctrl+N`/`Ctrl+P` 或 `Down`/`Up`  
    浏览补全列表。
    - `Enter`  
    插入选中的补全项。
    - `Escape`  
    关闭补全列表。

### 文本编辑
- `Shift+Left`, `Shift+Right`, `Shift+Up`, `Shift+Down`  
向左或向右扩展选择一个字符，或向上或向下扩展选择一行。
- `Ctrl+Shift+Left`, `Ctrl+Shift+Right`  
扩展选择到单词边界。
- `Ctrl+Shift+Up`, `Ctrl+Shift+Down`  
扩展选择到段落开头或结尾。
- `Shift+Home`, `Shift+End`  
扩展选择到当前行的开头或结尾。
- `Ctrl+Shift+Home`, `Ctrl+Shift+End`  
扩展选择到笔记的开头或结尾。
- `Ctrl+Shift+G`  
跳转到指定行。
- `Ctrl+C`/`Ctrl+X`  
没有选中文本时，复制或剪切当前行。
- `Ctrl+L`  
选择当前行。
- `Alt+Up`/`Alt+Down`  
向上或向下移动当前行。
- `Shift+Alt+Up`/`Shift+Alt+Down`  
向上或向下复制当前行。
- `Ctrl+Shift+K`  
删除当前行。
- `Ctrl+Shift+[`/`Ctrl+Shift+]`  
在支持折叠时，折叠或展开光标处的范围。

## Markdown 编辑器
### 阅读模式
请先点击渲染后的内容以使用阅读导航。以下导航键在演示模式中不生效。

以下导航键使用小写字母；`G` 表示 `Shift+G`。半屏滚动快捷键（`Ctrl+U`、`Ctrl+D`）即使在 macOS 下也使用键盘上的 **Control** 键。键盘缩放和重置快捷键（`Ctrl+=`、`Ctrl+-`、`Ctrl+0`）在 macOS 下使用 **Command** 键。

- `h`/`j`/`k`/`l`  
向左、下、上、右滚动。
- `Ctrl+U`  
向上滚动半屏。
- `Ctrl+D`  
向下滚动半屏。
- `gg`/`G`  
跳转到笔记开头或结尾（区分大小写）。
- `Ctrl+Wheel`  
使用鼠标滚轮放大或缩小（macOS 下为 `Command+Wheel`）。
- `Ctrl+鼠标左键拖动`  
向任意方向滚动（macOS 下为 `Command+鼠标左键拖动`）。
- 标题跳转（`<N>` 为可选次数，默认为 1）
    - `<N>[[`：向前跳转 `N` 个标题
    - `<N>]]`：向后跳转 `N` 个标题
    - `<N>[]`：向前跳转 `N` 个同层级的标题
    - `<N>][`：向后跳转 `N` 个同层级的标题
    - `<N>[{`：向前跳转 `N` 个高一层级的标题
    - `<N>]}`：向后跳转 `N` 个高一层级的标题

同层级和高一层级的跳转会在遇到更浅层级的章节边界时停止。如果当前章节标题已滚出视野，向前跳转可能先回到该标题。

### Markdown 演示
使用 `F9` 进入或退出演示模式，也可以使用 `Escape` 退出。在演示过程中：

- `Right`/`Space`  
切换到下一张幻灯片。
- `Left`/`Shift+Space`  
切换到上一张幻灯片。
- `Up`/`Down`  
在内容超出屏幕的幻灯片中滚动。
- `PageUp`/`PageDown`  
在当前幻灯片内滚动接近一页的距离。
- `Home`/`End`  
滚动到当前幻灯片内容的开头或结尾。

### 编辑模式
与所选输入模式的文本编辑器共享快捷键。

- `Ctrl+T`  
编辑当前笔记，或保存更改并退出编辑模式。
- `Ctrl+G, Q`  
放弃当前更改并退出编辑模式。
- `Ctrl+G, V`  
切换 Markdown 编辑器旁的实时预览。
- `Ctrl+G, B`  
打开当前笔记的标签弹出窗口。
- `Ctrl+G, I`  
打开片段选择器并插入片段（也适用于文本编辑器）。
- `Ctrl+Shift+V`  
交替粘贴：默认富文本粘贴时改用纯文本，默认纯文本粘贴时改用富文本。
- `Ctrl+G, Ctrl+P`  
将剪贴板中的 HTML 转换为 Markdown 后粘贴。

#### 文本编辑
选择多行文本时，行内格式会分别应用于各行的内容，并保留列表、引用和标题前缀。

- `Ctrl+B`  
将所选文本设为粗体，或在光标处插入粗体标记。
- `Ctrl+I`  
将所选文本设为斜体，或在光标处插入斜体标记。
- `Ctrl+;`  
将所选文本包裹为行内代码，或在光标处插入行内代码标记。
- `Ctrl+'`  
插入围栏代码块，或将所选行包裹到代码块中。在空代码块内重复此操作会移除围栏，但通常不会退出已有内容的代码块。
- `Ctrl+.`  
将所选文本包裹为行内公式，或在光标处插入行内公式标记。
- `Ctrl+G, .`  
插入公式块，或将所选行包裹到公式块中。在空公式块内重复此操作会移除分隔符。
- `Ctrl+G, M`  
使用 HTML `<mark>` 标签标记所选文本，或在光标处插入标签。
- `Ctrl+,`  
插入或编辑链接。
- `Ctrl+/`  
插入表格。
- `Ctrl+<Num>`  
插入级别为 `<Num>` 的标题，`<Num>` 为 1 到 6 的数字。作用于当前行或所选行。
- `Ctrl+7`  
移除当前行或所选行的标题标记。
- `Ctrl+8`/`Ctrl+9`  
在当前行或所选行插入无序或有序列表标记。
- `Tab`/`Shift+Tab`  
在 Markdown 源码中增加或减小缩进；有选区时作用于所选行。在可编辑的表格预览单元格中，则移到下一个或上一个单元格。
- `Shift+Enter`  
插入两个空格后换行，即 Markdown 硬换行。

## 导航模式
`Ctrl+G, W` 进入**导航模式**。VNote 会在主要部件和导航目标上显示一到两个字母，按下显示的字母即可跳转到对应目标。
