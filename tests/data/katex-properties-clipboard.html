2. 主要性质

  • 偶函数：sinc⁡(−x)=sinc⁡(x)sinc(−x)=sinc(x)。

  • 在 0 处取最大值 1。

  • 振荡衰减：随着 ∣x∣∣x∣ 增大，函数以 1/x1/x 的幅度衰减。

  • 积分：

    • 非归一化：∫−∞∞sin⁡xxdx=π∫−∞∞​xsinx​dx=π

    • 归一化：∫−∞∞sin⁡(πx)πxdx=1∫−∞∞​πxsin(πx)​dx=1

  • 傅里叶变换：

    • 归一化 sinc 的傅里叶变换是理想矩形窗：

      F{sinc⁡(t)}=rect⁡(f)F{sinc(t)}=rect(f)

      即在 ∣f∣<1/2∣f∣<1/2 内为 1，之外为 0（取决于傅里叶变换约定）。

    • 非归一化 sinc 的傅里叶变换对应宽度为 2 的矩形频谱，常差一个 ππ 因子。
