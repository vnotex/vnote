## v4.13.0
本次功能版本基于 VNote 4.12.0，带来大纲思维导图、可编辑的节点备注预览、按源类型导出及更完善的编辑体验：

* **思维导图与导航**
    * 将文档大纲打开为与源文档绑定的思维导图预览；若开头只有一个一级标题，则将其作为中心主题，并自动为分支配色
    * 大纲预览聚焦当前标题，点击节点可跳转到对应的源文档标题；大纲更改后需重新打开预览
    * 在与源文档绑定的纯文本预览中编辑思维导图节点备注，并正常自动保存；预览保持与源文档关联，不再提升为独立标签页
    * 紧凑排列节点图标，修复显示键盘快捷键下划线时“标签”文字被裁剪的问题
    * 思维导图 URL 右键菜单中，在“复制链接”之前新增“打开链接”，只读导图同样可用
    * Markdown、Typst 和思维导图中的右键菜单链接始终在新标签页打开，不受新标签页偏好设置影响
    * 本地文件及自定义协议的链接警告支持“不再询问”，所有警告路径共享已保存的选择
* **编辑与 Markdown**
    * 默认启用 Markdown 标记隐藏，并将长链接隐藏设置移至编辑器菜单；各项偏好独立保存，保留已有的禁用选择
    * 修复 Markdown 标题末尾标记的高亮，保留光标所在行的语法背景色；更新 vtextedit 及两份内置 cmark
    * 粘贴 Markdown 时保留预格式化及带类名提示的 HTML 代码块，包括缩进、语言提示和内嵌围栏，不复制代码块控件，也不吞掉周围正文
    * 将内置 Turndown 更新至 7.2.4，改进链接转义和有序列表缩进，同时保留 VNote 自定义粘贴规则
    * 为纯文本输入框新增 Ctrl+W 和 Ctrl+U 编辑快捷键；默认 Ctrl+8 和 Ctrl+9 改为插入未完成和已完成的任务列表，不再用于无序和有序列表
    * 将“切换原地预览”重命名为“原地预览”
* **导出**
    * 根据所选源类型提供导出目标和选项，支持原生 Typst 和 MindMap 源文件输出；在创建输出前拒绝不兼容的选择
    * 使用原生编译器将 Typst 导出为 HTML 和 PDF，保留作者指定的页面布局；导出原生源文件时复制内部相对路径图片，并提示未打包的导入文件或动态引用
    * 新增共享且可编辑的 `web/css/export.css` 样式表，用于 HTML 及基于 HTML 的 PDF/Custom 导出；升级时保留用户样式，不影响原生 Typst PDF
    * 简化选项名称，并说明自定义命令何时使用磁盘原始文件而非当前缓冲区快照
* **笔记本与界面**
    * 支持通过拖放调整标签的父子层级
    * 用独立的文字色和背景色菜单替代节点“标记”对话框，沿用现有 12 种颜色及 PDF 风格色块；“自动”仅清除所选颜色覆盖
    * Windows 和 macOS 的工具栏弹出输入框中，中文输入法不再将输入送入笔记编辑器，同时保留无边框关闭、溢出菜单、全屏焦点及自有对话框关闭后的焦点恢复
    * 将原生笔记本操作移至笔记本面板标题栏，让编辑器状态控件与边框保持内边距，并在调整尺寸时限制树列宽度的重复测量频率
    * 新建首次运行笔记本及手动添加的快速笔记方案使用 `Documents/vnote_notebook`，不迁移已有文件夹或已保存路径
    * 首次运行时重新打开已存在的默认笔记本，失败时不替换其内容；新增 `all-in-one.md`，并在快速访问列表为空时将其固定到列表
    * 新增默认“在当前笔记本中创建快速笔记”方案，使用 `Quick Notes/quick_note_%da%.md`；不迁移已有安装，内置中文欢迎笔记命名为 `Welcome_zh_CN.md`
    * 将本地化 VNote 提示从 12 条扩展至 64 条，涵盖 Markdown、导航、图片、PDF、思维导图、导出和自定义功能（[来源](https://github.com/vnotex/vnote-documentations)）
    * 升级后在新的只读标签页中打开本地化版本说明，提供简体中文说明，其他语言回退到英文
* **文档基础设施与可靠性**
    * 完整的 Text、Markdown、Typst、MindMap、PDF 和 Image 窗口支持由应用管理的内存文档，使用显式编辑器类型及加载/保存回调
    * 普通、加密及内存文档共享持久化提供器；异步保存内存快照时不清除较新的编辑，内存文档仅在会话内保留，并按能力限制仅适用于文件的操作
    * 无需临时文档文件即可渲染无根目录的 Typst 和基于字节数据的 PDF 文档
    * 改进原生 CI 的焦点、测试环境就绪及确认对话框处理，修复纯文本测试链接，并拆分 Typst 覆盖范围，不减少用例或延长测试时限
    * 内置编辑器测试遵循 `VNOTE_BUILD_TESTS`，保留 GIF 快照测试在本地按需启用并在 CI 中显式启用，同时为 macOS 安装包的 WebEngine 关闭预留更多时间
* **翻译**：更新简体中文（zh_CN）、日语（ja）及韩语（ko）翻译
