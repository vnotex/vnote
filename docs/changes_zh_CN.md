## v4.14.0
本次功能版本基于 VNote 4.13.0，带来按权限限定的 HTTP 自动化、更完善的 Markdown 粘贴及更流畅的导航体验：

* **HTTP 自动化与安全**
    * 新增默认关闭、仅监听回环地址的 HTTP API，供本地自动化客户端及管理员配置的 HTTPS 反向代理使用；令牌按笔记本授权，分别控制读取、实时读取、写入和移入回收站权限
    * 支持列出笔记、读取已保存或实时内容、搜索，以及有条件地创建、编辑、追加、重命名或移入回收站，不覆盖编辑器中的未保存更改，也不暴露受保护笔记
    * 强制使用可恢复的回收站，不回退到永久删除；保留保存与同步协调，并在退出时等待待处理操作完成
    * 在设置中管理令牌，提供独立的签发对话框、笔记本及权限选择、有效期预设或“永不过期”、默认 90 天有效期、一次性显示时的复制操作及即时撤销
    * 将监听设置存入本地会话配置，将 Windows 令牌校验数据存入本地用户配置目录；保留便携模式隔离，即使账户以提升权限运行也严格限制为仅所有者可访问
    * 使用保护隐私的结构化记录及共享请求 ID 审计请求、被拒绝的连接和异步修改结果；创建及重命名诊断不再包含笔记路径或原始异常详情
* **编辑与 Markdown**
    * 解析 HTML 为 Markdown 及粘贴时保留 KaTeX 和 MathML 公式：优先使用注解中的 TeX，注解被移除时恢复支持的 MathML，保留行内/独立公式及带标签的下花括号，不重复插入渲染文本
    * 避免为标题开头的编号添加不必要的转义，同时保留字面反斜杠及段落列表保护
    * 在新解析结果到达前保留并重新映射上次解析的标记隐藏状态，防止输入无关内容时 Markdown 标记闪烁
    * 在阅读模式代码块右键菜单的“导出”下方新增“折叠”和“展开”
    * 切换标签页时，在渲染前恢复已加载的 Markdown 页面的可见性，避免 WebEngine 空白画面，同时不让非活动页面持续运行
* **导航与思维导图**
    * 统一入口的普通输入用于跨笔记本搜索文件名；命令必须使用显式 `>` 前缀，空输入显示可用命令，默认启用“全部展开”并保留已保存的偏好
    * 关闭预览后将焦点恢复到源内容，包括思维导图画布
    * 改进思维导图字段菜单、快捷键编辑器及锚定到节点的弹出窗口，优化节点图标，并将非空备注指示器放在超链接指示器之前
    * 归类为“其他”的文件改用系统应用打开，不再使用纯文本编辑器；保留自动识别的文本/图片查看器，并在恢复会话时跳过不支持的标签页，不启动外部应用
* **界面与可靠性**
    * “文件夹排序”和“笔记排序”对话框默认增大至 800 × 600，并在列表中存在时选中触发操作的文件夹或笔记
    * 在内容下方为常驻编辑器状态栏预留空间，防止 Windows 状态及链接预览浮层将整个标签页容器提升为原生窗口
    * 垂直排列通知操作按钮，统一设置卡片表面及操作对齐，恢复完整的主题按钮边框，并明确编辑器工具栏选项提示
    * 根据已加载的界面翻译而非区域设置选择内置版本说明的语言
    * 改进原生 CI 凭据、弹出窗口及通知布局检查，保留首次失败诊断，并在 macOS 安装包挂载及 WebEngine 关闭遇到暂时性故障后自动恢复
* **翻译**：更新简体中文（zh_CN）、日语（ja）及韩语（ko）翻译
