## v4.14.2
本次改进版本基于 VNote 4.14.1，带来更安全的笔记本任务、Windows 集成及更流畅的编辑体验：

* **笔记本任务与安全**
    * 运行笔记本任务或求值其变量前，要求在本机信任该笔记本；重启后保留授权，显式关闭笔记本时清除授权，仅自动信任新建的本地笔记本
* **编辑与 Markdown**
    * 将两个 Markdown 标记隐藏开关替换为“不隐藏”“被动”和“积极”预设；默认使用“积极”且不迁移旧设置，将编辑体验选项映射为“积极”/“被动”，并在内嵌 Markdown 编辑器中使用“积极”模式
    * 更新 vtextedit，支持更长的紧凑链接目标地址，并在输入时将插入光标保持在隐藏的闭合标记内
    * 粘贴不含 TeX 注释的浏览器 MathML 时，恢复命名函数、极限、正体标识符及受支持的间距，包括 sinc 公式
* **Windows 集成与更新**
    * 通过“设置 → 文件关联”为已应用的内置文件后缀添加当前用户的“使用 VNote 阅读”和“使用 VNote 编辑”右键菜单；在独立窗口中阅读、在主窗口中编辑，并在启动及单实例转发时保留显式指定的模式
    * 同步已更改的右键菜单文件后缀，移除旧版针对所有文件的菜单项，无需管理员权限
    * 无需 REST API 即可检查 GitHub 和 Gitee 发布版本；显式请求 GitHub 更新时直接获取更新文件，避免发布元数据 API 的速率限制
    * 支持符合条件的 Windows 签名认证增量更新，在请求关闭应用前重建并验证完整目标文件，仅在安全回退规则允许时使用签名完整安装包
    * 使用轻量、适配主题的 Markdown 编辑器显示更新说明，并将上次更新检查时间迁移到本机的会话配置
* **界面与配置**
    * 仅在鼠标悬停于标签栏时显示视图分屏角落按钮，保持标签位置稳定、已打开菜单可用及独立窗口快捷键有效
    * 在独立窗口的置顶图钉旁添加“附加到主窗口”，将所有标签移至选中的主窗口分屏而不丢失未保存编辑或撤销历史；在切换主题后仍使图钉颜色与激活的“打开的窗口”按钮一致
    * 在主页和统一入口工具栏图标旁显示文字，与导出按钮保持一致
    * 从低于 `4.14.2` 的版本（包括 `4.14.1`）升级时，为空的已保存快速笔记方案列表恢复默认方案；保留自定义方案及后续主动清空列表的选择
    * 从低于 `4.14.1` 的版本升级且已保存列表非空时，补充缺失的默认统一入口别名，保留自定义定义及主动清空列表的选择
    * 更新中英文欢迎指南、README 截图及开发文档
* **可靠性**
    * 修复 CI 中的恢复归档、折叠数学预览几何布局、标题导航及实际视图链接测试夹具；在 CTest 中禁用反复超时的 Linux 视图区测试套件，同时保留其构建及 Windows 覆盖
* **翻译**：更新简体中文（zh_CN）、日语（ja）及韩语（ko）翻译
