## v4.14.4
本次改进版本基于 VNote 4.14.2，包含已取消发布的 4.14.3 的全部改动，带来更流畅的树形导航、更灵活的 Markdown 编辑及更完善的公式粘贴：

* **导航与任务**
    * 为视图窗口的思维导图操作添加 `Ctrl+G, F` 快捷键，可通过 `editor.core.shortcuts.MindMap` 配置；现有配置会继承该快捷键，除非已显式自定义或禁用
    * 仅有一个可用方案时直接创建快速笔记，无需打开方案选择器
    * 双击或按 Enter 时展开或折叠 Git 等任务容器，即使筛选隐藏了其子项也能操作；保持叶子任务的执行方式不变
* **界面**
    * 为任务、搜索结果、设置及统一入口的树形视图统一展开与折叠动画，与笔记本、标签及大纲保持一致
    * 缩小 Native 以外所有内置主题中树形视图的缩进及水平间距，同时保留行高；将行内重命名控件限制在行内，切回 Native 时恢复各树形视图原有的间距
    * 在笔记本、搜索及任务树的内容布局中计入主题边框和原生文本边距，使其与标准树形文本对齐；保留行高及图标、计数之间的间距
* **编辑与 Markdown**
    * 更新 vtextedit，使键盘和 Vi 导航对隐藏标记的光标边界处理保持一致，并在禁用持续隐藏时跳过不必要的光标处理
    * 将隐藏控件重命名为“标记隐藏”，并明确“无”“温和”“适中”和“强烈”预设的设置说明
    * 添加“适中”隐藏模式：隐藏支持的 Markdown 标记和链接语法，光标移入时显示，并缩短较长的图片和引用网址
    * 提供三种 Markdown 编辑体验，从低于 `4.14.4` 的版本升级时再次显示选择提示；在确认新选择前保留已保存的标记隐藏预设
    * 修复以 TeX 命令结尾的 MathML 公式粘贴，按标记角色恢复符号，并保留标识符的字体变体
    * 将可读宽度工具栏提示从思维导图编辑器设置移至通用的编辑器设置
* **翻译**：更新简体中文（zh_CN）及日语（ja）翻译
