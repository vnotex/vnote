## v4.14.1
本次改进版本基于 VNote 4.14.0，带来源文档联动的大纲编辑、更稳定的 Markdown 预览及更流畅的导航体验：

* **大纲与思维导图**
    * 通过工具栏思维导图预览编辑 Markdown 及具有可靠源映射的 Typst 标题：重命名主题、添加子节点或同级节点，并在确认后移动章节，支持与源文档配对的撤销/重做
    * 将接受的编辑直接应用到源文档，并沿用其自动保存、备份文件或不保存策略；关闭无法应用的主题草稿时可选择丢弃或取消，不会丢弃已应用到源文档的更改
    * 只读源文档、PDF 大纲及不支持的映射仅允许导航；生成的思维导图仅允许基本的主题及结构编辑，源文档发生独立更改后需重新打开预览
    * 将大纲面板及弹出窗口中的排序功能扩展到普通思维导图和具有可靠源映射的 Typst 章节，保留层级、章节内容及撤销历史
    * 导航到源标题时保持大纲思维导图预览打开且保有焦点，避免重复章节编号，并在源更新完成前保留新添加的主题
* **编辑与 Markdown**
    * 编辑时保持 Markdown 格式标记隐藏，光标移动会跳过这些标记；保留进入链接时显示标记的行为及现有隐藏开关
    * 首次打开 Markdown 视图时询问隐藏还是显示 Markdown 标记，记住选择，并提示以后可通过工具栏菜单更改
    * 更新 vtextedit，改进折叠后的源标题及预览位置，在被动布局及展开时保持视口稳定，并改善输入法组合输入期间 Markdown 标记隐藏的稳定性
    * 防止 Markdown 阅读器中原地预览准备阶段的闪烁，修复阅读导航恢复及视图销毁生命周期问题
* **界面与可靠性**
    * 将统一入口的“全部展开”偏好移至独立的设置页面，同时保留已保存的选择
    * 根据实际使用的应用语言而非区域设置选择 VNote 提示
    * 在较窄的视图窗口工具栏中保持现有主题的溢出指示器清晰可见，不再裁剪为灰色方块
    * 在显示独立窗口前先附加文档视图，避免首帧空白
    * 更新 vxcore，整合经桌面验证的移动端分支，包括可信根目录别名处理及私有长路径测试夹具修复
    * 通过测试实际的视图窗口实现修复控件 CI 链接问题
* **翻译**：更新简体中文（zh_CN）及日语（ja）翻译
