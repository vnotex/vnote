## v4.15.0
本次功能版本基于 VNote 4.14.4，带来原生 TODO 规划器、仪表盘任务管理，以及更完善的编辑和更新体验：

* **TODO 规划器**
    * 添加基于 Markdown 的原生 `.todo` 编辑器，提供仅显示任务的界面、全宽布局，以及独立于全局保存策略的自动保存
    * 使用标题分组组织列表，将默认分组中的列表显示在顶层，并支持列表和分组拖动、复制、描述及每个列表独立的表情图标
    * 通过“我的一天”“重要”和“计划”视图、搜索及标签筛选、截止日期、Markdown 备注和嵌套检查步骤规划任务
    * 直接切换完成状态、重要性及“我的一天”归属；通过任务右键菜单和键盘快捷键执行常用操作、设置日期及跨列表移动任务
    * 通过列表菜单按重要性、截止日期、加入“我的一天”的日期、名称或创建日期排序，并可恢复手动顺序
    * 改进任务详情、圆形勾选控件、已完成步骤的删除线、计数徽章及可折叠的“已完成”区域；在窄窗口中仍可使用侧栏导航
    * 将已完成任务归档到同目录下的 `.archived.todo` 文件，保留备注、步骤及元数据；保留源文件中的分组和列表，移动未完成时报告错误而不丢弃归档
* **仪表盘**
    * 为新建和重置的仪表盘添加 TODOs 贴纸，保留已有布局；可选择实际列表或“我的一天”“重要”和“计划”视图
    * 添加快速任务输入、按日历所选截止日期筛选、完成和重要性控件，以及与 TODO 编辑器共享的可折叠“已完成”区域
    * 双击贴纸中的任务或按 Enter 打开任务，单击选择或切换控件时不跳转；提供仅含图标的“编辑”和“设置”操作
    * 在会话配置中记住贴纸的关联文件，并在不覆盖已有内容的前提下创建缺失的 TODO 文件
* **编辑与 Markdown**
    * 为可编辑的嵌入式 Markdown 编辑器（包括 TODO 任务备注）添加共享格式工具栏及可配置的编辑快捷键，并修复工具栏溢出按钮样式
    * 使用 InsertMark 插入原生 Markdown 标记，并恢复同时包含上下限的 MathML 公式
    * 连续输入两个空引用行后退出块引用；在折叠块之后插入新行，包括 VSCode 和 Vi 输入模式
    * 对新配置或缺失的设置默认关闭 Markdown 自动章节编号，同时保留已保存的偏好和大纲面板的默认设置
    * 选中文本时隐藏代码块右键菜单中的“折叠”和“展开”操作
* **界面**
    * 使用鼠标滚轮滚动超出可见范围的视图标签，而不切换当前文档
    * 将共享计数徽章固定在浏览器树形视图的可见右边缘；延迟加载直接带有标签的笔记数量，并保留选择状态
    * 使网页滚动条的颜色和滑块宽度与原生控件一致，并让编辑器状态标签使用当前主题颜色
* **Windows 更新与可靠性**
    * 在手动检查更新对话框中提供需明确触发的 Windows“立即更新”操作，同时保持常规更新检查仅检查、不安装
    * 显示与发布来源对应的版本说明，并在 VNote 已是最新版本时显示内置版本说明
    * 在用户确认新安装正常工作后，提供清理保留的 Windows 更新备份的选项
    * 修复不支持文件身份信息的 Windows 共享文件夹中误报的图片资源发布错误，同时保留禁止覆盖及重解析点检查
* **翻译**：更新简体中文（zh_CN）及日语（ja）翻译
