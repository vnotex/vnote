## v4.15.2
本次维护版本基于 VNote 4.15.1，带来更稳定的 TODO 规划、更顺畅的 Markdown 编辑和更清晰的文件导航：

* **TODO 规划器**
    * 修复跨午夜时“我的一天”操作和任务行标签的状态，包括已过期的“我的一天”归属
    * 再次单击已选中的任务即可切换任务详情的显示与隐藏
    * 修复侧边栏分组拖放排序，并将分组排列在未分组列表之前
    * 在不同 TODO 文件及重启后保留任务排序方式，可选择“手动”恢复文档顺序
    * 禁用 TODO 编辑器中的文档缩放，保持任务布局稳定
* **Markdown 与图片**
    * 在 Markdown 编辑模式下为裸 URL 提供“打开链接”和“复制链接”，使用解析后的链接目标并排除代码内容
    * 修复文档末尾存在折叠内容时光标跳动的问题
    * 防止打开“插入表格”弹出面板时的鼠标释放事件同时触发其对话框
    * 新配置及图片格式设置缺失或无效时，剪贴板图片默认保存为无损 PNG；已保存 JPEG 设置的配置继续使用 JPEG，并将编码质量提高到 100（[#2791](https://github.com/vnotex/vnote/issues/2791)）
* **导航与界面**
    * 使用上游 Tabler 图标，为节点浏览器添加内置文件类型图标
    * 恢复 Pure 主题中的树分支连接线，同时保留展开和折叠箭头
* **翻译**：更新简体中文（zh_CN）及日语（ja）翻译
