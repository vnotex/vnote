## v4.15.1
本次改进版本基于 VNote 4.15.0，带来更流畅的 TODO 规划、统一的编辑器设置和更高效的笔记本搜索：

* **TODO 规划器与仪表盘**
    * 在编辑结束时提交列表名称，并在切换列表或保存时保留尚未提交的名称
    * 单击即可展开或折叠 TODO 分组，并让任务备注填满详情面板的可用空间
    * 在 TODO 编辑器和仪表盘贴纸的重要性星标旁添加“我的一天”图标标记，可直接切换任务归属
    * 在切换列表、窄窗口布局和重启后记住“列表”及“任务详情”面板的宽度，并修复列表表情图标被裁剪的问题
* **编辑与界面**
    * 默认以编辑模式打开笔记；从低于 `4.15.1` 的版本升级时，将之前的打开模式重置为编辑模式，之后保存的阅读模式偏好仍会得到保留
    * 在共享的“输入模式”设置中统一管理 Normal、Vi 和 VSCode 模式，保留文本及 Markdown 编辑器的已有选择
    * 保持空的隐藏标记 Markdown 元素可见，并为思维导图节点备注使用便笺图标
    * 在笔记和文件夹属性中按应用语言区域显示创建及修改时间，同时保留本地时间和秒数
* **搜索与可靠性**
    * 为文件夹列表、搜索和标签使用类型化的 vxcore 结果，避免进程内 JSON 往返转换，同时保留元数据、排序及已有 JSON API
    * 移除 ripgrep 后端，使用内置搜索，以提供一致的 Unicode 替换和协作式取消行为
    * 批量处理 HTTP API 中原始笔记本搜索的元数据检查（[#2789](https://github.com/vnotex/vnote/pull/2789)）
    * 修复普通后代节点缺少索引元数据时无法删除笔记本文件夹的问题，同时保留受保护文件和不安全路径检查
* **翻译**：更新简体中文（zh_CN）及日语（ja）翻译
