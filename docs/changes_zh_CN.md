## v4.12.0
本次功能版本基于 VNote 4.11.0，带来可编辑的链接预览、原生 Markdown 渲染、Typst 数学公式及更强的安全防护：

* **链接预览与导航**
    * 无需离开当前笔记，即可在可编辑的浮层中预览支持的文件链接；使用“打开链接”可正常打开文件，点击源笔记的背景区域可关闭预览
    * 将预览标签页打开到来源工作区，无需重新打开编辑器，也不会丢失草稿和撤销历史；替换重复标签页时会遵循“保存”“放弃”和“取消”的选择
    * Markdown 编辑器中须按住 Ctrl 并单击才能打开链接，普通单击仅定位光标
    * Markdown 阅读模式的链接菜单中，“打开链接”位于“复制链接”之前；链接和图片菜单不再显示无关的“编辑”和“导出”操作
    * 文件打开设置支持指定现有的主窗口或独立窗口分屏，保留后台选择状态；目标不可用时报告错误，不再改用其他位置打开
* **Markdown 与 Typst**
    * 在阅读模式、实时预览和 WebEngine 导出中使用 cmark 原生渲染 Markdown，复用编辑器当前的语法树，同时保留双链、任务、提示块和目录功能
    * 移除表情短代码及文本表情的自动展开，已输入的 Unicode 表情保持不变
    * 新增可选的 Typst Markdown 数学公式渲染器，支持已授权解锁的加密笔记、原位预览、自包含 HTML/PDF 导出和跨应用复制；KaTeX 仍为默认选项，选择 Typst 后须在原有的美元符号分隔符内使用 Typst 语法
    * 围栏 `typst` 代码块不受数学公式设置影响，作为自包含标记文档渲染，并在预览、导出和跨应用复制中保留作者指定的页面布局及多页输出
    * 移除 Markdown 中 Typst 代码块的默认页边距，使其与周围内容对齐；显式设置的页边距和独立文档布局保持不变
    * 用内置共享运行库和数量受限的后台工作线程替代 Typst 辅助进程，保留预览、导出及有序退出功能
    * 自动发现已安装的系统字体，修复 Typst 预览和导出中的中文缺字问题，同时保留已配置字体的优先级
    * Typst 编辑器字体和预览背景跟随当前主题，包括 Typst 专用覆盖设置；文档中显式指定的样式优先，主题预览颜色不影响导出
    * 移除 Typst PDF 预览中的信息浮层，保留错误及编译诊断；确认关闭文档后清理不再使用的 Typst 图片
    * 在阅读器延迟获得焦点或原生窗口重建时保留演示模式请求，防止过期的 PDF 状态或 WebChannel 重新绑定干扰替换后的笔记
    * 编辑器章节编号仅作用于 ATX 标题，不再为 Setext 标题编号
* **安全与任务**
    * 修复 Markdown 原始 HTML 的 URL 过滤绕过问题，在阅读器、实时预览和导出中装入内容之前，验证经浏览器解码后的 URL
    * 在“Markdown 编辑器 → 阅读”中新增可搜索的“保护 Markdown 免受 XSS 攻击”设置；加密笔记始终启用过滤
    * 防止通过文件名、选中文本及其他变量注入任务命令：Shell 命令和选项必须为静态内容，变量值应置于按字面值传递的 `args` 中，且不再递归展开
    * 迁移内置 Git 提交任务，并提供自定义任务迁移指引；带参数的 Shell 任务必须使用 Bash 或 PowerShell，否则应使用 `type: process`
    * Markdown、Typst 和思维导图共享外部链接警告及“不再询问”偏好，同时保留授权、取消、过期视图检查，以及独立的本地文件警告
* **思维导图与界面**
    * 新增图片右键操作，支持查看、复制、复制源地址及可撤销的缩放；隐藏会暴露 URL 或 Base64 数据的图片提示
    * 思维导图节点属性面板的位置设置立即生效，无需重新打开编辑器，也不会丢失编辑；独立窗口中的属性面板保持内嵌，不改变主窗口偏好
    * 移动标签页后激活独立窗口并将焦点置于其编辑器
    * 搜索面板支持滚动，修复通知文字换行后的布局，以及非整数显示缩放下 Mermaid 标签的换行问题
    * macOS 工具栏弹出面板不再显示原生标题栏，点击外部或按 Escape 即可关闭，与 Windows 保持一致
    * 统一编辑器内表格边框和链接预览按钮的主题样式，并在主题切换时刷新；Lucius 主题使用统一的段落标记作为标题链接符号
* **同步与兼容性**
    * Git 笔记本同步在 HTTPS 和文件 URL 之外新增 HTTP 支持；建议使用 HTTPS，因为 HTTP 会以明文传输凭据及数据
    * 更新内置 KSyntaxHighlighting 6.30.0 资源，包含 464 种语法定义和 31 个高亮主题；默认浅色语法主题改为 Catppuccin Latte，同时保留界面主题的专用覆盖设置
    * 在浅色和深色主题切换时及时更新共享 Markdown 预览主题，包括仅编辑模式下的标签页，确保数学公式使用正确的前景色
    * 精简 macOS 安装包中未使用的依赖，并在发布前通过原生 Apple Silicon 和 Intel 运行器验证签名后的安装包；保留两种 macOS 安装包
    * 使用随包提供的 xcb 平台验证 Linux AppImage，修复 Windows 打包暂存流程及独立思维导图测试的链接问题，改进原生测试输入和诊断报告的保留机制
* **翻译**：更新简体中文（zh_CN）、日语（ja）及韩语（ko）翻译
